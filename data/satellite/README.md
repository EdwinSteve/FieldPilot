# Satellite scenes

Read by `ImageryLoader` (`backend/app/satellite/scenes.py`, D058–D060).
Each scene is a folder with `scene.json` (red and near-infrared bands,
reflectance 0–1, and each zone's area as a normalized box keyed by zone
name) and `rgb.png` (the image sent to SAM 3.1).

| Scene | Location | Date | Content |
|---|---|---|---|
| `neiva-2026-10-28` | 2.95, -75.30 (demo farm in Neiva, Huila) | 2026-10-28 | **Synthetic.** Zona 1 healthy (mean NDVI 0.80); Zona 2 stressed with three brown bare-soil patches (mean NDVI 0.38, below the 0.4 demo threshold) |

The scene is generated by `backend/scripts/generate_demo_scene.py`, which
is deterministic: run it again and the files are identical. On 2026-10-30,
SAM 3.1 with the prompt `brown patch` found exactly the three patches in
`rgb.png` (D059).
